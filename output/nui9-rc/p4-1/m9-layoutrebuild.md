## 入口（真实路径）
分镜页工具栏 [页菜单 ▾] → ContextMenu「重建本页版式…」→ 模态窗口 [重建本页版式]：
警示文案 + 本页格数 3~8 选择 + 版式（动态错落/均衡网格）+ 状态行「当前第 1 页为 4 格。」
+ [取消] [确认重建]。

## 实机时间线
1. 物理点击 [页菜单 ▾] → Popup 菜单弹出（焦点 Menu）→ Invoke「重建本页版式…」→ 对话框打开。
2. Esc → 关闭，焦点返还触发按钮 [页菜单 ▾]（精确到触发钮）。
3. 再开 → 点 [取消] → 关闭，焦点再次返还 [页菜单 ▾]。
4. 确认支线（错误分支实测）：[确认重建] → PATCH /pages/{id}/layout → 服务端 409
   「当前页缺少剧本或原文追溯，不能调整格数」（apply_page_layout 守卫：source_coverage
   无 ranges 且 beat_ids/scene_ids 为空——种子页是旧版分页数据，结构横幅也提示
   「这是旧版分页数据，不能直接生图」）→ 客户端弹出 [重建未完成] 错误框（焦点在
   [确定]），关闭后面板未被重建（DB 面板 id 不变）。
