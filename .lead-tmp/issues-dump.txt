#468 [P3][Desktop Red Team][native] '..' in a user-controlled query value makes the request unsendable — delete-project is permanently blocked for names containing '..'
**Found:** native read-only audit (2026-09-12, HEAD fe22969 lineage). Native paths change-forbidden — this Issue is the deliverable for the WPF owner.

## Mechanism

`apps/desktop/native/Services/ApiClient.cs:217-221`:

```csharp
private static void Validate(string path)
{
    if (path.StartsWith('/') || path.Contains("://", StringComparison.Ordinal) || path.Contains(".."))
        throw new ArgumentException("无效的 API 路径");
}
```

`Validate` runs on the **full path including the query string**, and the query encoding leaves `.` unescaped (`HttpUtility.UrlEncode` / `Uri.EscapeDataString` treat `.` as RFC 3986 unreserved). So any user-controlled query value containing `..` survives encoding into `path?query` and trips the substring check — the request is never sent.

## Repro

**A (data-destructive op permanently blocked):** create a project named e.g. `序章..终章` → 项目设置 → danger zone → type the exact name → 删除项目 → every attempt fails with "删除未完成：无效的 API 路径". The project cannot be deleted from the desktop client (`Views/ProjectSettingsView.cs:384`).

**B:** 场景资产 tab → type `东京..雨` in 地点前缀 → the debounce fires `ReloadAsync` → every load fails with "场景资产无法载入：无效的 API 路径" until the text is manually cleared (`Views/SceneWorkspace.cs:108`).

## Severity

P3: a legitimate free-text value permanently blocks a data-destructive operation (A) or a whole view's data load (B); no workaround inside the client.

## Existing tests

`NativeSceneChecks.cs:53-54` only asserts well-formed filter params arrive; nothing covers hostile/free-text query values.

## Suggested fix surface (native owner)

Split `Validate` on `?` and apply the `..` traversal check to the **path segment only** (the query is URL-encoded; encoded `..` in a query value is harmless data), or drop the substring check for the query portion while keeping the path-segment checks (`/:/://`). Add checks: a project named with `..` can be deleted; a scene filter containing `..` loads.
