## 1. 当前入口与摩擦（≥15 处证据）

今日没有「对画面说话」的表面。名叫导演的东西有三处，互不相通。

### 1.1 「导演」只是生图提示语气

1. 新建项目可选 `DIRECTOR`，文案「每个阶段等待确认」（`apps/web/app/page.tsx:119-121`）。
2. 项目设置同样三档工作方式（`apps/web/app/projects/[id]/settings/page.tsx:80-84`）。
3. 后端几乎只把它写进提示词：「导演模式：严格执行已给出的格位、镜头、人物、服装和动作，不擅自改动。」（`apps/api/app/services/prompt_compiler.py:134-137`）。解析剧本也按 mode 换指令（`worker_handlers/story_parse.py:143`）。
4. `WorkflowMode` 枚举存在（`domain/states.py:6-7`，`models.py:74-75`），**没有**命令表、预览 API、撤销栈。选 DIRECTOR 不会出现命令栏。

### 1.2 生成台是整页抽卡，不是导演台

5. 生成段标题「DRAW / 单页抽卡」「每次只生成 1 页」（`generate-section.tsx:99`）。主按钮始终「生成 1 个 1K 彩色候选」（`:139`）。
6. `generateCandidate` 绑定 `batchId + storyboard_version + 整页参考选择`（`api.ts:988-992`，`use-generation-workspace.ts:183-196`）。没有 panel_id、mask、自然语言。
7. 点击图只打开 lightbox「放大查看」（`shared.tsx:67-78`）。没有「对这张图下指令」。
8. 暂选要 `window.confirm` 人工校对文字（`generate-section.tsx:142`）。收藏 ≠ 采用（同文件批次说明）。
9. 旧分镜候选走 stale 横幅：沿用并重新检查 / 按当前 V 重新生成（`:103`，`keepSelectedCandidate` `api.ts:1004-1011`）。这是版本决策，不是命令预览。
10. 「修复单格 / 气泡区域 / 整页」来自检查分类映射（`display.ts:3-6`，`inspection-panel.tsx:28-34`），用户不能先看见将改哪一格。修复直接 `repairCandidate.mutate(inspection)`，无 diff、无费用、无模型确认。
11. 生成失败只在条下 `form-error`（`generate-section.tsx:140`）。费用估算在任务中心（`jobs-section.tsx:20-26,:77`），生成按钮旁写死「1K · 彩色 · 1 个候选」，不显示预估金额。

### 1.3 工作流是阶段门，不是自然语言

12. 工作流运行有 `WAITING_APPROVAL`（`workflow-studio.tsx:98,:636`）：生图节点要选手动模型/分辨率；否则链到「前往采用」。确认继续 = 放行 DAG，不是解析一句话。
13. 可运行已发布流程、节点、从这里运行、取消（`:571,:635`）。没有命令历史。保存/发布有自己的草稿版本（`:571`）。
14. 导航把「流程编排」放在步骤列表外（`workspace-chrome.tsx:78`），与生成台分离。

### 1.4 分镜页是表单导演，不是选区

15. 分镜检查器叫「分镜导演台」（`storyboard-editor.tsx:254`），编辑的是景别/动作/人物/气泡文字。格子是联系表按钮（`:249`），单击选格，不能多选，不能点气泡几何（气泡只在右侧卡片 `:270-272`）。
16. 保存即 PATCH 并 bump `storyboard_version`（后端 `mark_storyboard_changed`）。没有「预览这条改动将使 N 个候选过期」的独立确认层——只有成功 notice 里带候选过期数（`storyboard-editor.tsx:120`）。
17. 改格数会删光本页 Panel/Dialogue（`content_workflow.py` `update_page_layout`），与「对第 3 格说一句」的粒度相反。

### 1.5 项目页与任务

18. 工作台步骤无「导演」（`labels.ts:16-23`：原作→资产→剧本→分镜→生成→库→任务）。
19. 任务中心能取消/重试/看结果（`jobs-section.tsx:78,:84-85`），结果点击再进 lightbox。不能把失败任务「改口令重发」。
20. QueueDock 只跳任务中心（`workspace-chrome.tsx:122`），不承载对话。

**结论：** DIRECTOR 是提示风格 + 工作流审批点 + 分镜表单。自然语言导演工作台需要 **新表面**，但必须复用现有选中页、选中格、暂选候选、任务取消/费用、lightbox，而不是平行造一套生成。

## 2. 目标信息架构

不新开独立产品。导演是工作台 **模式**，挂在当前页的画布上下文上。

推荐入口（实现时三选一，本文推荐 A）：

| 方案 | 做法 | 取舍 |
| --- | --- | --- |
| **A. 生成台内导演模式（推荐首发）** | `/projects/{id}/generate` 增加「导演」开关；左侧/主区仍是当前页图+格叠加；底部命令栏 + 右侧历史 | 用户已在看候选；局部修改也从这里进 V02-43 |
| B. 分镜页内导演 | 命令改的是分镜字段而非像素 | 与「改图」用户预期不符 |
| C. 新路由 `/director` | 干净 | 多一个步骤，和抽卡抢上下文 |

工作流 `WAITING_APPROVAL` 保持 DAG 门；导演命令 **不是** 工作流节点。DAG 仍按页生成/检查/采用。命令产生的是派生候选或分镜 PATCH，由现有任务系统执行。

### 2.1 四槽

```
┌ 页条 / 候选条 / 模式：抽卡 | 导演 ──────────────────────────┐
│ ┌ 画布（当前采用或查看中的候选 + 格轮廓） ┐ ┌ 检查/历史 ┐ │
│ │ 选区高亮：格、气泡、角色徽章、整页框     │ │ 命令时间线 │ │
│ │                                         │ │ 解析预览   │ │
│ └─────────────────────────────────────────┘ └────────────┘ │
│ ┌ 作用域芯片 ┐ ┌ 命令输入 ──────────────┐ [预览] [执行]   │
└ 状态：解析中 / 待确认 / 执行中 / 失败 · 模型 · 费用估算    ┘
```

900–1279：历史改抽屉；命令栏固定底（在 QueueDock 之上）。不要把输入塞进 48px dock。

### 2.2 作用域（必须可点、可说、可芯片）

| 作用域 | 如何建立 | 默认风险 |
| --- | --- | --- |
| 单图 / 当前候选 | 画布背景或候选卡 | 中：局部像素，不换分镜 |
| 单格 | 点格轮廓 | 中：V02-43 局部或整格重绘 |
| 多选格 | Shift 加选（分镜画布未落地前可用格列表多选） | 高：多区域 |
| 角色 | 点格内角色徽章或检查器人物 | 中：可能跨格 |
| 场景 | 点背景或场景名 | 高：可能跨页 |
| 气泡 | 点气泡框或检查器气泡卡 | 低–中：文字 vs 气泡几何 |
| 整页 | 明确芯片「整页」或口令含「这一页」 | 高：接近现有整页生成 |

**无选区 + 含糊口令 = 不得执行。** 进入「待澄清」：列出候选目标，用户点一个或取消。禁止默认为整页。

短命令可直接预览的例子：「把第 3 格雨下大一点」（已选格 03）→ 预览卡片即可。  
歧义例子：「让她转过身」（页上两个女性角色）→ 必须点角色。

### 2.3 命令生命周期（UI，schema 开放）

```
空闲 → 输入/语音草稿
    → 解析中（role=status）
    → 预览（结构化 diff，未调用生图）
    → 用户确认（低风险可一次点「预览并执行」若解析置信高且作用域唯一）
    → 排队/执行中（现有 Job）
    → 成功：新候选或分镜草稿，不自动暂选
    → 失败：留在历史，可改口令重发
```

高风险（整页、多格、场景、删除、跨页、估计费用超过阈值、模型不支持局部）**禁止**「预览并执行」合并按钮。必须两步。

解析失败与执行失败分开：前者不产生 Job；后者有 job_id，走取消/重试。

## 3. 预览卡必须展示的字段

预览是导演台的主决策面，不是聊天泡泡。

| 块 | 内容 | 现成来源 |
| --- | --- | --- |
| 作用域 | 页、格阅读序、候选 ordinal、角色名、气泡序号 | 分镜 `reading_order`、候选卡 |
| 意图摘要 | 一句中文，禁止英文枚举进主文 | 待 V02-40 解析器 |
| 预计变更 | 像素 / 分镜字段 / 两者；列出将过期的检查类别 | 现生产门禁五类 |
| 调用模型 | 当前 `activeDrawModel`，可改 | `ImageModelPicker`（`shared.tsx:7-22`） |
| 费用 | 币种 + 估算/不可估算，**不等于账单** | 任务中心已有语义（`jobs-section.tsx:20-26`） |
| 能力缺口 | 模型无 mask/局部 → 明确「将改为整格重绘」或拒绝 | V02-44；UI 不得静默整页 |
| 风险 | 多格、跨页、不可逆分镜 PATCH | |

确认后才 `POST` 执行。预览请求应是便宜文本调用或纯规则；实现 Issue 若无法廉价预览，则本地规则预览 + 标注「模型尚未解释」，不得假装已理解。

撤销：

- 未执行：丢弃预览。
- 已执行未暂选：删除或归档派生候选（现 `deleteCandidate` 禁止删已暂选，`generate-section.tsx:142`）。
- 已暂选：必须先撤回暂选（`retractSelectedCandidate` `api.ts:1013-1014`）再处理。
- 分镜字段命令：走分镜 version 乐观锁；冲突文案对齐「分镜格已被更新，请刷新后重试」。

## 4. 历史、重试、刷新、冲突

命令历史是右侧时间线，每条：原文、作用域芯片、状态、job 链接、费用、结果缩略图。

- **重试**：同一 payload 再入队；进行中禁用。
- **修改后重发**：打开原文到输入框，作用域保留，重新解析（可能变歧义）。
- **刷新恢复**：历史必须服务端（V02-40）。禁止只放 `sessionStorage`。刷新后画布回到该页暂选候选，历史滚动到未完成条。
- **并发**：同一页已有 PAGE_GENERATE/REPAIR 进行中，新命令默认排队或提示「等当前图完成」。禁止并行两个整页生成（现生成钮在 pending 时禁用，`:139`，导演应同样）。
- **分镜 version 冲突**：预览时记下 `storyboard_version`；执行时 409 → 展示 stale，类似生成台横幅，不得用旧 version 强写。

工作流运行与导演命令并行：允许看 DAG，但导演执行仍走 Job。不要在 WAITING_APPROVAL 里塞自然语言框。

## 5. 如何进入局部修改（不替代 V02-43 / V02-03）

导演预览若意图是「改这块像素」且作用域是单图或单格：

1. 主按钮「在选区编辑」打开 V02-43 局部编辑器，带入当前候选、格 bounds、命令原文作为注释。
2. 用户画 mask / 框选后生成派生候选。
3. 导演历史记一条「已转为局部编辑」，job 血缘由 V02-42 定义。

导演预览若意图是改分镜文字/镜头：留在分镜 PATCH 路径，不进 mask。

本文 **不** 规定命令 JSON、mask 编码、父候选字段。开放问题交给 V02-03A/V02-40/V02-42。

## 6. 键盘、焦点、无障碍、小窗口

- 焦点：`` ` `` 或 `Ctrl+K` 聚焦命令框（实现时避开输入框冲突）。Esc 关闭预览/澄清层，焦点回画布选区。
- Tab：作用域芯片 → 输入 → 预览 → 确认（确认默认不是危险按钮）。
- 画布选格：方向键（与 V02-31 草案对齐，但本实现可先用格列表）。
- 读屏：作用域变化 `aria-live="polite"`；预览卡 `role="region"` 标题「命令预览」；错误 `role="alert"`。
- 命令框 `aria-label="导演指令"`，不要 placeholder 当唯一说明。
- 小窗口 900–1279：预览改 modal；历史抽屉；芯片换行。不要横向挤模型选择+费用+执行。
- reduced motion：预览出现用 opacity。
- 对比：预览主按钮用现有 `.button.ink`，不要 8px 灰字费用。
