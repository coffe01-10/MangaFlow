## 运行边界

- 统一闭环使用确定性假模型，覆盖全部业务状态与文件产物，不产生 Vertex 费用。
- 真实 Vertex 验收限定为单页、单个 1K 候选，不自动修复、升清、生成第二页或自动采用。
- 复杂图层、多用户协作、移动端和无人值守整章生成不属于 MVP。
