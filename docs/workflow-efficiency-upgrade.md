# 流程编排效率升级

本次改动针对 Web 流程编排工作台。现有执行器、数据库事务、Worker 和图片生成确认机制保持原有契约。

## 交互

- 画布拖拽框选，Shift / Ctrl / Cmd 多选；批量移动、复制、删除、对齐和等距分布。复制保留选区内部连线。Ctrl+D 复制、Ctrl+G 分组、Ctrl+Z 撤销。
- 分组保存名称、颜色、备注、成员和折叠状态。折叠用代理节点展示边界端口；真实节点与执行连线不改变。解散分组保留节点。
- Ctrl+K 打开全局命令中心，搜索应用页面、当前项目工作流和画布节点，执行添加、运行、发布、查看版本等操作。
- 拖线到空白处搜索兼容节点，双击连线插入节点并连接两端。最近使用和收藏保存在当前浏览器。
- 新建流程可以套用单页生成、检查修复、批量出图、整章导出或空白模板。自定义模板保存在当前浏览器，跨设备迁移使用 JSON 导出 / 导入。
- 节点显示本次运行状态、耗时、结果字段数量和已完整上报的 Token；点击查看结果。运行中的节点和入边使用 CSS 动画，支持 prefers-reduced-motion。可选跟随运行镜头。

## 模板与执行范围

检查修复模板从已有候选的采用确认节点开始，检查失败后通过生成页完成修复，再采用并重新检查；不提供自动修复闭环。批量出图模板从已有分镜的生成节点开始，为所选页面逐个提交独立运行，逐页确认模型和结果。失败页面保留在选择中；已成功提交的运行可从运行列表查看。

## 数据与接口

schema_version 仍为 2，WorkflowGraph 新增可选字段：

- groups：id、name、color（十六进制颜色）、notes、node_ids、collapsed。组 ID 唯一且不与节点冲突；每个成员必须存在且只能属于一个组。
- run_mode：single / batch，编辑器偏好，默认 single。
- entry_node_ids：模板推荐入口，默认空数组。Web 启动流程时读取已发布版本的入口，提交现有 start_node_ids 参数。

这些字段存储在现有 JSON 图谱中，无数据库迁移。旧客户端未实现这些编辑器字段，重新保存前应注意兼容性。

GET /workflow-templates/{check|batch} 返回内置模板。运行列表和详情只读聚合关联任务的 ModelCallAttempt：只计本次运行时间范围内的尝试，完整输入/输出计数才能给出 total_tokens；缺失或部分上报返回 null，不显示为零。
