# 市场综合分析:四份调研的横向对比

> 综合日期:2026-10-05。输入:`竞品调研.md`、`创作者需求调研.md`、`技术趋势调研.md`、`商业模式调研.md`(同目录)。本文只做横向归并与判断,事实细节以各源报告为准;源报告中标注「估算/传闻/来源有限」的结论在此继承同样限制。
> 面向对象:MangaFlow(私有单用户、本地优先、供应商平权的编排型 AI 漫画工作台)。

## 摘要

四份报告从完全不同的切入角度(竞品/用户/技术/商业)收敛到同一个结论:**这个赛道的竞争者集体死在"一键生成"上,而所有独立证据链都指向"有治理的半自动工作流"是真空位。** 具体说:

- 三个不同来源(竞品盘点、创作者社区、司法判例)各自独立地把"人工确认 + 可追溯"顶到最高优先级——竞品没人做、创作者点名要、版权法奖励它。这是全场最强的重叠信号。
- 角色一致性本身已不再是机会——技术趋势报告显示它正在以 API 级速度商品化(Nano Banana / FLUX.2 / StoryDiffusion),**机会在一致性之上的"资产规范层"**,四份报告对此判断一致。
- 技术侧的新变量是"成本阶梯化"(同族模型价差 10 倍)与"供应商生命周期"(2026 年已有两个停服实例),两者都让"用量账本 + 供应商平权"从加分项变成生存项。

**前三名机会点(详见末节排序):**

1. **「可追溯的人工决策链」作为版权合规卖点**——把逐页人工确认/校对记录从内部架构讲成"可登记版权、可过平台披露审查"的外部价值。
2. **版本化角色资产包 → 多图参考槽位映射**——一致性商品化后,护城河是"资产即规范"的编排层,且模型端输入形态已官方背书。
3. **用量账本驱动的成本透明与分层路由**——便宜档抽卡 + 贵档定稿,派发前给档位×分辨率估算;打竞品积分制的成本盲区。

## 五、给路线图的三条建议

1. **v1 营销叙事换锚点**:从"AI 画漫画工具"换成"让 AI 漫画的创作过程可证明"。对标话术:"一键生成无法挽回 vs 决策权在创作者"(需求:99);"人类编排证据链 vs 提示词截图"(商业:72)。
2. **技术债优先级**:能力位契约细化(多图上限/编辑模式/文字编辑/档位/视频)> 价格表 schema 扩展(档位×分辨率×通道)> 账本秒计费。三者都是现有框架内的增量(技术:98-104)。
3. **不做清单固化**:不自建一致性技术、不做纯云订阅、不押平台分成、不为本地通道另造一致性方案——四条均有跨源证据支撑(本节二、三部分)。
