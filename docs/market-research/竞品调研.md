# AI 漫画 / Webtoon 生成工具竞品调研

> 调研日期：2026-10-05。信息来源以各产品官网、维基百科、GitHub 仓库、Product Hunt、Hugging Face 为准；
> 标注「估算 / 传闻 / 来源有限」处均为无法从一手来源核实的数字。

## 摘要

当前「AI 画漫画」赛道呈现两极分化：一端是 Midjourney / NovelAI / Stable Diffusion 这类**通用生图引擎**，画质强但没有漫画工作流概念；另一端是 ComicAI、Dashtoon、Anifusion、AI Comic Factory 这类**一键生成式漫画工具**，把「提示词 → 整篇漫画」做成黑盒，但普遍缺乏逐页人工控制、可追溯性与资产管理，且商业模式脆弱——本次调研期间，Dashtoon Studio 已于 2026-08-15 关停并转向 AI 视频短剧平台 Frameo，ComicAI 已更名为 SkyReels 并转向 AI 视频，开源的 AI Comic Factory 仓库已于 2025-10-31 归档停止维护。**几乎没有竞品在做「导演视角 + 逐页人工确认 + 结构化资产可追溯」的严肃创作工作台**，这正是 MangaFlow 的空位。

## 分项发现

### 一、通用生图引擎（无漫画工作流，但构成画质与成本基准）

#### 1. Midjourney

- **核心能力**：通用文生图服务，Discord 机器人 + 网页端访问。Character Reference（cref）支持跨图角色一致性；Niji 模型专门针对动漫风格调优。（来源：en.wikipedia.org/wiki/Midjourney）
- **定价**：Basic $10/月、Standard $30/月、Pro $60/月、Mega $120/月；年付 8 折。（来源：docs.midjourney.com/docs/plans）
- **目标用户**：概念艺术家快速原型、广告公司头脑风暴、建筑师情绪板；被 Corriere della Sera 用于出版漫画、被用于整本儿童绘本 Alice and Sparkle。
- **强项**：画质天花板；cref + Niji 已能满足多数动漫角色的跨格一致性。
- **弱项**：没有分镜、格子、台词气泡、叙事结构的概念；漫画全靠用户在 Prompt 里硬写"comic panel"或后期手工拼版；闭源、仅云端、无本地部署；多起版权诉讼（2023 艺术家集体诉讼、2025 迪士尼/环球、2025 华纳兄弟探索）。

#### 2. NovelAI（Anlatan）

- **核心能力**：云端订阅制 SaaS，AI 辅助小说写作 + NovelAI Diffusion（基于 Danbooru 数据训练的 Stable Diffusion 变体）动漫图像生成；支持图生图、ControlNet、inpainting、Director Tools、内置画布。ToS 声明生成内容归用户所有，生成图不存储于服务器。（来源：en.wikipedia.org/wiki/NovelAI、novelai.net）
- **定价**：订阅 $10/月起，图像与文本生成都包含；另有按需点数 Anlas。（来源：novelai.net 官网首页）
- **目标用户**：小说作者 + 动漫/二次元爱好者；在日本市场尤其流行。
- **强项**：写作与画图一体（和 MangaFlow 的"小说 → 漫画"链路在入口端重合）；动漫风格专门训练；隐私声明友好。
- **弱项**：仍是"单张图 + 文本"范式，无页面/分镜/资产绑定/批量校验工作流；训练数据争议（Danbooru 公开声明不背书其使用）与 2022 年源码泄露事件。

#### 3. Stable Diffusion 本地生态（ComfyUI / AUTOMATIC1111 / Fooocus + ControlNet + LoRA）

- **核心能力**：开源权重模型（SD3.5 用 Community License，年收入 < $1M 免费），可在消费级显卡（优化后低至 2.4GB 显存）甚至 CPU 本地运行。生态组件：ControlNet（姿势/深度/边缘条件控制）、DreamBooth/Textual Inversion/LoRA（角色与风格微调）、ComfyUI 节点式流程编排、A1111 功能全家桶、社区动漫微调（waifu diffusion 等）。（来源：en.wikipedia.org/wiki/Stable_Diffusion）
- **定价**：模型本身免费；成本是本地 GPU 与时间。
- **目标用户**：技术向创作者、工作室管线。
- **强项**：完全本地、可控性最强、LoRA 角色一致性与姿势控制是事实标准；生成图归用户。
- **弱项**：**没有"漫画"这个产品概念**——用户要自己拼 ComfyUI 节点 + 手动分镜 + 外部排版，工具链门槛极高；众所周知的崩手/文字渲染问题（SDXL/SD3 有改善但未根治）；版权诉讼与宽松内容政策的争议。

> **小结**：这一层的工具决定了"单格抽卡"的画质与成本水位，但把「组织成一部漫画」的全部工作留给用户。MangaFlow 的单页抽卡 + 多批次候选在体验上会被直接拿来和 Midjourney/SD 比画质，但它的价值在组织层。

### 二、专用 AI 漫画工具（有漫画概念，但多为黑盒一键生成）

#### 4. ComicAI → SkyReels（已转向）

- **核心能力**：2023-04-28 在 Product Hunt 以 ComicAI 发布，主打"故事 → 漫画/日漫"，自动生成脚本、角色与画面；类 Canva 画布、面板模板、对话气泡、story-to-comic 转换。用户反馈：跨格角色一致性会漂移、复杂分镜模板不足。（来源：producthunt.com/products/comicai）
- **定价**：Product Hunt 页面未列出；当前官网 skyreels.ai 抓取内容为空，价格未能核实（来源有限）。
- **现状**：产品已更名 **SkyReels**（2025-02-20 再发布），方向转向 AI 视频生成。漫画功能是否保留未能从官网确认。
- **启示意义**：这条路线（一键 story-to-comic）的商业验证不足，厂商自己转向了短视频。

#### 5. Dashtoon / Dashtoon Studio（已关停）

- **核心能力**：2022 年末创立的数字漫画创作平台（Writer Beware 称"digital comics creation platform"），网站定位"Read and create your own comics, manga and manhwa online"，创作端 Dashtoon Studio 提供 AI 生图 + 角色一致性 + 面板编辑；同时运营读者端付费内容平台（"cheaper than other comic apps"）。（来源：web.archive.org 2025 年快照、bing 检索到的 Writer Beware 条目）
- **定价**：Studio 定价页存在但抓取失败，具体价格未能核实（来源有限）。
- **现状**：**Dashtoon Studio 于 2026-08-15 关停**，用户被导向新平台 Frameo（AI 视频与短剧）。（来源：dashtoon.com/create/ 官方公告）
- **启示意义**：曾经最接近"AI 漫画工作室"定位的商业竞品也未能跑通云端订阅模式——其双端（读者平台 + 创作工具）投入重，最终整体转向视频短剧。佐证了"AI 漫画工具作为独立云服务"的脆弱性。

#### 6. Anifusion（CodeConda）

- **核心能力**：网页端 AI 漫画工作室。选面板布局 → 自然语言描述 → AI 出图；内置画布编辑器（对话气泡、竖排文字、日漫字体）；角色表复用 + 六视图参考生成；inpainting、脸部增强、姿势控制、草图生图、视频动画、**LoRA 训练**；多模型（AnimagineXL、FLUX、SDXL、Pony 等）；风格预设（吉卜力、海贼王、火影等）；REST API / 托管 MCP 接口；社区画廊。（来源：anifusion.ai、anifusion.ai/pricing）
- **定价**：Free $0（100 积分）/ Creator $9/月（2,000 积分 + API）/ Pro $24/月（10,000 积分，单价更低）；单图 5–100 积分按模型计；积分永久有效；企业定制价。（来源：anifusion.ai/pricing）
- **目标用户**："缺画功的准漫画家"、webcomic 作者、爱好者、工作室、以及通过 API 集成的开发者；仅桌面端。
- **强项**：本赛道里功能最完整的现役产品——面板布局 + 编辑器 + 角色表 + LoRA + API 全齐；积分制透明。
- **弱项**：仍是"生成器"心智——按格/按页生成，没有公开证据显示有原作文本→剧本→分镜的结构化管线、逐页人工确认门槛、版本化资产规范或可审计的成本账本；作品与资产留在云端。

#### 7. ComicsMaker.ai

- **核心能力**：官网自描述"Generate Comics with AI | AI Comic Generator | AI Comic Strip Maker"；页面抓取仅得标题，功能/定价细节未能核实（来源有限）。
- **定位推测**：与 ComicAI 同类的轻量在线生成器。

#### 8. AI Comic Factory（开源，已归档）

- **核心能力**：Hugging Face Space（11.3k 赞）+ 开源 Next.js 应用，Apache-2.0。LLM（Zephyr/GPT-4/Claude/Mixtral 可插拔）生成故事 JSON → SDXL 渲染面板，单提示词出一页漫画；可接 HF Inference、Replicate、自托管 TGI。（来源：github.com/jbilcke-hf/ai-comic-factory、huggingface.co/spaces/jbilcke-hf/ai-comic-factory）
- **定价**：开源免费，成本即各后端 API 费用。
- **弱项**：需要自己拼装前端/后端/LLM/渲染四个组件，非一键部署；角色一致性无专门机制；**仓库 2025-10-31 起归档只读，停止维护**。
- **启示意义**："LLM 写分镜 JSON + SD 出图"的技术路线证明可行也证明不够——缺少资产与确认环节时产出不可控，社区热度不足以维持维护。

#### 9. LlamaGen.AI

- **核心能力**：文本/角色描述/图片/故事点子 → 漫画、webtoon、manhwa、manga；宣称"IP 漫画演员库"保证跨格一致性、4K 分辨率、单次最多 64 个 storyboard、多格式转换（storyboard/小说/视频/音频/视觉小说）、50 种语言、社交平台分享。（来源：llamagen.ai）
- **定价**：官网宣称免费（schema 标注 $0），未列出付费档（来源有限，"600K+ 创作者"等数字为官方宣传口径）。
- **目标用户**：无画功的漫画/同人创作者、写作者、教师。
- **弱项**：营销话术重于可验证功能；无证据显示有人工确认、资产管理或本地化能力。

#### 10. Toona

- **核心能力**：AI 动漫工具箱而非漫画生成器：图生视频、漫画上色、图片/视频放大至 4K、补帧至 60/120/240fps、首尾帧中间帧、背景抠除/填充、"motion painter"局部动效。（来源：toona.io）
- **定价**：当前全部"Try now free"，beta 阶段经 Discord/邮箱准入；无付费档。
- **启示意义**：后处理段（上色/放大/补帧/动效）是漫画工具链的相邻生态位，MangaFlow 未来做条漫→动效漫/视频导出时这类工具是直接竞争者或集成对象。

### 三、研究项目（技术储备，非产品）

#### 11. StoryDiffusion（南开大学 + 字节跳动，NeurIPS 2024 Spotlight）

- **核心能力**：consistent self-attention 机制让角色（含多角色）跨图保持一致，热插拔兼容所有 SD1.5/SDXL 模型；配 motion predictor 可把生成图序列变成长视频。Comic_Generation.ipynb 与低显存 Gradio demo（>20GB 显存，A10 24GB 实测）可直接生成一致角色漫画。（来源：github.com/HVision-NKU/StoryDiffusion、storydiffusion.github.io、huggingface.co/spaces/YupengZhou/StoryDiffusion）
- **性质**：Apache-2.0 开源研究项目 + HF 免费 demo，非商业产品；部分视频权重仍未发布。
- **意义**：学术界已把"免训练角色一致性"做成可插拔件——意味着一致性本身在快速商品化，**不构成任何产品的护城河**；护城河只能在一致性之上的工作流与资产层。

### 四、平台方动向（渠道在收缩，不是在造工具）

- **WEBTOON（Naver）**：平台商业模式为免费 + Coins/Fast Pass 付费解锁 + 广告 + IP 改编分成；**自身不提供漫画生成工具**。最近的 AI 动作是 2026-04 与 AI 头像公司 Genies 合作把角色变成可交互 AI 头像——方向是 IP 运营而非创作工具。（来源：en.wikipedia.org/wiki/Webtoon_(platform)）
- **Kakao 系**：Kakao Webtoon 并入 KakaoPage、海外服务收缩；Tapas（2021 年约 $510M 收购）宣布 2026 年内关停，重心转向 Piccoma 等 IP 业务。Kakao 的 AI 表述停留在"内容+用户数据+AI 运营能力"层面，无创作者生成工具。（来源：en.wikipedia.org/wiki/Kakao_Webtoon、en.wikipedia.org/wiki/Tapas_(website)）
- **意义**：大平台把 AI 用在 IP 衍生与运营上，**把"怎么画出来"留给创作者**；平台收创作端收缩意味着创作者更依赖自主工具，但平台方短期内不太可能成为 MangaFlow 的直接竞品。

### 五、"漫画工厂"类应用

- 检索"manga factory / comic factory"类应用，结果主要指向 Hugging Face 的 AI Comic Factory（见第 8 项，已归档）与大量同名漫画**阅读**站（MangaTown、Manga Fox、MangaToon 等），未发现其他成规模的现役生成型产品。该品类整体呈"演示级多、产品级少、存活率低"状态。

## 对 MangaFlow 的启示

### 竞品没做好的地方（MangaFlow 的空位）

1. **没有人在做"导演工作台"，都在做"自动贩卖机"**。现役工具（Anifusion、LlamaGen、ComicsMaker）全是"输入提示词 → 吐出一篇漫画"的黑盒；用户无法逐页抽卡、跨模型候选并存、收藏与采用分离、撤回不删原图。MangaFlow 的"逐页人工确认采用"是品类内独一份的决策权设计。
2. **可追溯性完全缺席**。所有竞品都是"提示词 → 图片"一次性派生；没有竞品把原作修订、来源区间、分镜、提示词快照、图片连成一条可回溯链。当用户需要"改第三章第二句台词并重出受影响的两格"时，现有工具只能整篇重抽。
3. **角色一致性在快速商品化，"资产即规范"才有壁垒**。cref、LoRA、consistent self-attention 让一致性本身不再是护城河；但把人物/服装/风格/场景做成一级资产、把版本化角色模型包在排队时冻结进 prompt_snapshot、概念图须人工确认才成为规范——这套"规范层"没有竞品实现。
4. **成本与用量账本是盲区**。云端积分制（Anifusion 5–100 积分/图）把真实成本藏进点数；没有任何工具提供逐次派发、pending → 归一化 usage、估算与 billed 对账分开的账本。对在意成本的可变价格 API 用户这是刚需。
5. **云端订阅模式已被证伪两次**。Dashtoon 关停、ComicAI 转向视频、AI Comic Factory 归档——纯云端"AI 漫画 SaaS"要么烧不出留存要么主动转型。**本地优先 + 私有单用户 + 自带 API key** 的模式反而没有运维成本包袱，与用户资产所有权诉求一致（NovelAI 与 SD 的"生成物归用户"声明证明用户在意这一点）。
6. **供应商锁定是普遍默认**。所有专用工具都捆绑自家模型/积分；没有竞品做 OpenAI/Anthropic/Vertex/CLI 多通道共用一个目录、能力位、健康路由的平权平台，更没有 fail-closed 的区域编辑能力声明。
7. **SD 生态什么都能做但什么都不帮你做**。ComfyUI 可控性最强，却把分镜、资产绑定、校对、导出全部留给用户手工拼装；MangaFlow 的机会是把"ComfyUI 级可控性"产品化成"导演视角的流水线"，而不是在单图质量上和它硬拼。

### 需要正视的竞争压力

- **画质基准**：单格抽卡效果会被直接对比 Midjourney/Niji 与 SDXL 微调，MangaFlow 依赖外部模型是正确选择，但意味着"生成质量"不是卖点，"组织质量"才是。
- **免费挤压**：LlamaGen 宣称免费、Toona beta 免费、Anifusion 有免费档；MangaFlow 若走付费，必须把价值锚在严肃创作者的工时节省（资产管理、返工成本、可回溯修订）而非出图数量。
- **相邻生态位**：上色/放大/补帧/动效（Toona 类）和视频化（SkyReels、Dashtoon→Frameo 的转型方向）是竞品正在涌入的方向；条漫→视频导出若列入路线图需提前定位与这些工具的关系（集成 vs 自建）。
- **信息缺口**：ComicAI/SkyReels 现行定价、ComicsMaker 详细功能、Dashtoon Studio 历史定价均未能从一手来源核实（官网抓取失败或已下线），如需精确对标建议补充付费工具评测或 Archive 深挖。
