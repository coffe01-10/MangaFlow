# AI 漫画/创意工具商业模式调研

> 调研日期:2026-10-05。调研对象:AI 漫画与创意工具的收费形态、创作者平台变现路径、版权与平台政策风险;结论面向 MangaFlow(私有单用户、本地优先的 AI 漫画工作台,含 Web 与 Windows WPF 双端)的变现与增长路径。
> 产品事实来源:本次任务提供的产品背景摘要(引用 README.zh-CN.md / docs/architecture.md / docs/development-progress.md / docs/roadmap.md 行号),以及仓库内 `docs/pub-01b-webtoon-export-contract.md`(条漫导出契约,已读)。
> 外部信息来源:下文每条判断注明公开来源;网络抓取中未取到的具体数字(如 KakaoPage/快看分成比例、NovelAI 完整价目)标注为「来源有限」或「估算」,不编造。

## 摘要

1. **工具侧主流模式已收敛为「免费/低价入口 + 订阅积分制 + 企业定制」三段式**:Scenario(AI 资产生成)为 50 免费日积分 + $10/$30/$50 月订阅 + 定制企业版;NovelAI 从 $10/月起订并保留按需购币(Anlas)作为补充;Clip Studio Paint 采用桌面买断(约 $63 起)与全端订阅($0.99/月起)并行,大版本升级对买断用户另收升级费或「Update Pass」。**纯订阅与纯买断都在让位给混合制**。
2. **模型成本是真实变量成本,且「本地免费 + 云端付费」是被验证的分层**:Stable Diffusion 系权重开放、年营收 100 万美元以下商用免费(> $1M 需企业授权),意味着本地推理可以合法零边际成本;而云端图像按 token 计价(OpenAI gpt-image 系图像输出 $8–$40/百万 token,Midjourney/Firefly 用订阅+生成额度包装同样的成本)。**工具厂商普遍按量收云模型费、对本地模型不收或收功能费**,这与 MangaFlow「供应商平权 + 逐次派发用量账本」的架构天然吻合。
3. **创作者变现侧:平台分成透明区间约 50%–70%,但 AI 内容正在被系统性要求披露、且在部分平台实质受限**。有据可查:Tapas 广告分成约 70%、付费章节分成 50%;Webtoon Canvas 按浏览付费 + Coins 打赏 + IP 改编(2020–21 两年向英文创作者支付超 $2700 万,韩国头部创作者年均约 $25 万美元);Steam 2024 年起强制商店页 AI 披露;Amazon KDP 强制申报 AI 生成内容(文本/插图/封面,「AI 生成后大量人工修改仍算 AI 生成」)。美国版权局立场:纯 AI 生成不可登记,**含人类创造性选择/编排/修改的 AI 辅助作品可登记**——这直接抬高了「人工确认/逐页校对/可追溯」类工具的价值。
4. **对 MangaFlow 的一句话结论**:最可行的路径是「开源或低价的核心工作台 + 官方托管的云模型用量(按量/订阅额度)+ 面向工作室的团队/商业授权」,把「可追溯的人工决策」卖成合规卖点;增长上先做 Webtoon/Tapas/抖音条漫导出的创作者社区渗透,再谈工具→平台分成。

## 分项发现

### 1. 订阅 vs 按量计费:行业实际是「订阅打底 + 按量补充」的混合制

| 工具 | 模式 | 价格点(来源) |
| --- | --- | --- |
| Clip Studio Paint | 桌面买断 + 全端订阅并行;移动端仅订阅 | 买断 from US$63(官网促销页,Windows/macOS);订阅 from US$0.99/月;Pro/EX 分层(EX 含多页漫画、动画)。2023 年 3 月起大版本升级对买断用户收升级费或 12 个月 Update Pass(Wikipedia: Clip_Studio_Paint) |
| Scenario | 积分制订阅 + 免费日额度 + 企业定制 | 免费 50 credits/日;Starter $10/月 1,500 credits;Pro $30/月 5,000;Max $50/月 10,000;Enterprise 定制(官网抓取)。年付约省 33% |
| NovelAI | 订阅为主 + 按需 Anlas 购币 | "subscriptions start at $10/month",含图像与文本生成;另有 on-demand Anlas 购买(官网) |
| Adobe Firefly | 订阅 + 生成额度(generative credits) | 官网仅见个人/学生/企业三档结构,具体额度页 403 未取到(来源有限) |
| Civitai | 社区 + Buzz 虚拟货币 + 悬赏(Bounties) | Buzz 可购买或社区赚取,用于站内生成(Wikipedia: Civitai);会员价目未取到 |
| OpenAI API(底层成本参照) | 纯按量 | gpt-image 系图像输出 $8–$40/百万 token;文本旗舰 $2–$10/百万输入 token(developers.openai.com/api/docs/pricing) |
| Stable Diffusion / Stability | 权重开放 + 企业授权 | Community License:营收 > $1M 的企业需付费 Enterprise License;普通商用免费且输出权利归用户(Wikipedia: Stable_Diffusion) |

**判断**:
- 创意工具的定价轴心从「功能解锁」转向「算力额度」。订阅解决收入可预期,按量解决重度用户成本回收,二者并存是常态而非过渡形态。
- 买断制(Clip Studio)在桌面专业工具里仍有真实需求——尤其反感订阅的插画/漫画老用户群体——但厂商通过「大版本升级费/Update Pass」把长期维护成本重新转回周期收费。MangaFlow 若做买断,需要预设同样的大版本收费机制,否则买断价必须显著定高。
- 「本地模型免费跑、云模型按量收费」是有先例的健康分层:Stability 模式证明权重开放的商用合法性(营收 $1M 阈值),MangaFlow 用户自带 SD 系本地推理时工具方零边际成本;云端则天然适合代充代付+额度包。

### 2. 创作者变现路径:分成透明,头部集中,IP 改编是长尾上限

- **Webtoon(Naver)**:Canvas 自助上传按浏览付费;PPS(Page Profit Share)广告分成自 2013 年起;Coins 打赏/Fast Pass/Daily Pass 付费解锁;2020–21 两年向 12 万+ 英文创作者支付超 $2700 万;韩国头部创作者年均约 $25 万美元,最高 2021 年约 $900 万;IP 改编通过 Webtoon Studios/Wattpad Webtoon Studios 约 300 个影视动画项目在开发(来源:Wikipedia: Webtoon_(platform))。**具体分成百分比未公开**。
- **Tapas**:Ink 虚拟货币解锁/打赏;作品满 100 订阅可享广告分成约 70%;付费章节(Premium)创作者分成 50%;2020 年向创作者支付约 $1400 万(来源:Wikipedia: Tapas_(website))。
- **快看(Kuaikan)**:本次未取到可靠官方分成数据(维基词条 404;来源有限)。公开口径(过往招股书报道)为「付费阅读 + 广告 + IP 授权」三支柱,具体比例**估算/传闻**,建议以快看创作者后台公示为准。
- **抖音漫画号**:抖音本身无漫画频道分成;变现路径是「账号引流(漫画解说/条漫更新)→ 直播打赏(1000 粉开播门槛)→ 星图商单 → 橱窗带货/小程序付费」,本质是自媒体变现而非平台稿费(来源:Wikipedia: Douyin 中 TikTok 侧打赏/电商机制;国内漫画号玩法为公开运营常识,来源有限)。
- **共性**:平台分成区间有据可查约 **50%–70% 归创作者**(Tapas 两档正好给出上下限);腰部以下收入微薄,真正的大钱在 IP 改编(影视/出版/周边),而 IP 改编恰恰要求**权利链清晰**——见下节。

### 3. 版权与平台政策风险:披露义务正在普及,可版权性奖励「人在回路」

- **美国版权局**:纯 AI 生成不可登记;2023 年 3 月指引 + 2025 年 1 月澄清明确:只要人类创造性表达可辨识(创意编排、选择、修改),AI 辅助作品可登记;Thaler v. Perlmutter 确立机器不可为作者;至 2026 年 3 月最高法院拒绝复审(来源:Wikipedia: Artificial_intelligence_and_copyright)。中国侧相反:北京互联网法院 2023 年 11 月认可 AI 生成图片可受著作权保护——同一作品在中美两法域的可版权性结论可能相反。
- **Amazon KDP**:必须申报 AI 生成内容(文本/插图/封面/翻译),且「AI 生成后做大量人工修改仍算 AI 生成」;AI 辅助(自己创作、AI 修改润色)无需申报(来源:kdp.amazon.com 帮助页)。
- **Steam**:2024 年 1 月起要求开发者在商店页披露 AI 生成内容及防违法内容的措施;开发者需对 AI 内容拥有权利(来源:Wikipedia: Steam_(service))。
- **平台趋势小结**:政策方向不是「禁 AI」,而是「披露 + 权利责任下沉给上传者」。对工具方的含义:(a) 用户需要证明创作过程留痕;(b) 模型/素材权利链(用了什么模型、什么 LoRA、什么参考图)会越来越被平台和合作方询问。

### 4. 「工具 → 平台」分成模式:先例存在但不是早期该做的事

- Civitai 的悬赏/Buzz 经济是「工具内建交易市场」的样本:用户发悬赏、完成者赚 Buzz,Buzz 回头买站内生成——形成闭环但本质是流量平台逻辑。
- Webtoon/Tapas 的工具关系是「平台吃内容、工具吃订阅」,目前**没有主流平台给漫画制作工具分成**的公开案例;反向案例是 Patreon 与 Webtoon 的合作(Naver 向达标创作者每月 $1000)——平台补贴的是创作者,不是工具。
- 判断:工具→平台分成(如「用 MangaFlow 制作的作品在平台获益时抽成」)在单用户工具阶段既无杠杆也无合规抓手,**应排到第三阶段以后**;更现实的是「工具内嵌投稿通道」(如 WEBTOON 切片规格已进导出契约)→ 换取平台侧推荐位/创作者入驻,属 BD 而非收入模式。

### 5. 企业/工作室版需求

- Scenario 企业版卖点清单可作行业参照:IP 治理("Your IP stays yours")、SOC 2 Type II、SSO/SAML、审计日志、规模基础设施(官网抓取)。
- 漫画工作室的真实差异需求(从 MangaFlow 架构反推):多用户/审阅流、资产库共享与权限、用量成本归集到项目/客户、素材与模型权利链审计、私有部署。当前 MangaFlow 是单用户+SQLite+回环绑定(README.zh-CN.md:113、:145-152),**团队版是需要新增多用户与审计能力的产品线,而不是现有版本的加价档**。

## 对 MangaFlow 的启示

### 变现路径建议(分三阶段)

1. **现阶段(v1.0 RC):BYOK(自带密钥)免费/低价,先铺量。**
   - 产品是私有单用户、凭据服务端加密(README.zh-CN.md:113),天然支持用户填自己的 OpenAI/Vertex/CLI 凭据——工具方零算力成本。
   - 定价参照:免费 + 可选付费许可(买断制大版本收费,参考 CSP 的 Update Pass 机制,或 $X/年更新订阅)。**不建议现阶段做托管算力**——供应商平权 + 用量账本已能把云成本透明转给用户。
   - 合规卖点:逐页人工确认 + 五类视觉检查 + 来源关联(docs/architecture.md:7、:132)正好对上美国版权局「人类创造性编排可登记」与 KDP/Steam 披露义务——应把「创作过程留痕=可声明人类 authorship」写成营销点,这在 AI 工具里是差异化。

2. **第二阶段:托管用量与团队/商业授权。**
   - 云模型代充:在用量账本(逐次 pending audit + usage 归一化,README.zh-CN.md:158-160)之上加官方额度包/按量代付,用户免配 API key。定价=成本×加成,账本透明本身就是卖点。
   - 工作室版:多用户、共享资产库、审阅、项目级成本归集、私有部署——对标 Scenario Enterprise 清单,这是真正可收年费的档位。**估算定价区间:$20–$50/席/月**(参照 Scenario Pro/Max 档位与创意 SaaS 惯例,属估算)。
   - 条漫导出(WEBTOON preset,docs/pub-01b-webtoon-export-contract.md)已是投 Webtoon/Tapas 生态的现成钩子;可加「一键生成平台投稿规格包(含 AI 披露声明模板)」直接吃政策红利。

3. **第三阶段:平台化,谨慎。**
   - 创作者社区/资产市场(角色模型包、风格资产的交易)比「作品分成」更现实:资产是结构化、可版本化的(prompt_snapshot 冻结规范),比成品图更适合做 marketplace。
   - 与漫画平台谈工具合作/认证(投稿规格内嵌 → 平台导流)属 BD;抽成模式无先例,不作收入假设。

### 风险提示

- **AI 内容披露义务会随平台扩散**(KDP/Steam 已落地):导出产物应内嵌可读的制作元数据(模型、人工确认记录),否则下游投稿环节会把责任抛回用户。这是功能项也是卖点。
- **可版权性双法域分裂**:中国认可 AI 生成图可版权、美国不认——服务两国创作者时「人工参与度」叙事对两边都安全。
- **本地模型的商用边界**:SD 3.5 系 Community License 对营收 >$1M 实体收费;MangaFlow 若日后做企业版且预打包开源权重,需跟踪各模型许可阈值(当前逐条接入 CLI/API 模式下责任在用户侧,风险低)。
- **不要把收入模型押在平台分成上**:主流漫画平台无给工具分成的公开先例;Webtoon/Tapas 分成(50%–70% 给创作者)是**用户的**收入,MangaFlow 的对应打法是降低用户达到平台门槛的成本(投稿规格、披露模板、更新节奏)。
