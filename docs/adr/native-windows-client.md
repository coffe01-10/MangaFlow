# Windows 原生客户端重构

2026-09-07：用户明确要求原生桌面技术并授权重构。本记录替代此前 Tauri
作为唯一桌面界面的决定；保留既有客户端供迁移期使用。

## 设计与风险

界面使用 C# / WPF，当前构建目标为本机可验证的 .NET 8。没有 HTML、WebView、
Next.js 或 Node 渲染依赖。发布前须迁移到仍受支持的 .NET LTS 并独立验证安装包。
FastAPI、数据模型、供应商凭据、付费动作门禁保持服务端所有权。

本轮为 L3：新增原生宿主与应用生命周期。由 lead 直接设计、实现、验收，
不修改既有 shell-core 的握手和 Job Object 所有权实现。

WPF 立即显示窗口，异步启动独立 Rust native-host；后者复用 shell-core 启动
Python helper，校验 READY / token / PID / journal / health 后经 stdout 返回
回环 origin。原生界面只访问该 origin，不自动连接固定端口或未知后端。
不启用 fake-channel，不启动 Node。测试通过显式环境开关启用 stub。

WPF 独占写入宿主 stdin，关窗关闭管道；崩溃也产生 EOF。宿主在握手前启动 EOF
监听，握手完成后处理已到达的退出信号，协作停止 helper 后记录 journal。
因此启动期间关窗的清理上界为握手期限加停机期限，而非即时取消。
宿主强杀时复用 Windows KILL_ON_JOB_CLOSE 清理 sidecar 树。
UI 启动失败、服务断开、请求超时需显示具体错误并提供显式重试。

新客户端默认数据根为 LocalAppData/MangaFlow/Native，避免与运行中的旧壳同时
打开同一 SQLite；可显式指定已有数据目录（须先关闭其他客户端并备份）。
命名 Mutex 以规范化数据根为作用域，防止两个原生客户端占用同一目录。
不自动搬迁数据库、不自动恢复付费任务、不复制供应商密钥。

## 界面合同

- 常驻项目侧栏、搜索、项目内导航；窗口尺寸与最近项目持久化。
- 原生新建项目、正文粘贴 / TXT / Markdown 文件选择、章节原文阅读。
- 项目任务列表：状态、进度、错误原因、手动取消；付费重试须明确确认。
- 原生运行设置编辑使用版本令牌；409 保留输入并要求重新加载。
- 快速切换 Ctrl+K、新建 Ctrl+N、刷新 F5、退出对话框 Esc。
- HTTP 异步；视图切换取消读取，并以请求代次拒绝迟到结果。
- 列表启用容器回收 / 虚拟化；后台刷新不重建整个窗口，不重置编辑表单。

## 迁移边界

这一原生入口不等于现有 Web 工作台的所有功能已迁移。供应商配置、资产编辑、
分镜画布、导演与生成审阅须逐条迁移和验收，不能用嵌入网页或假按钮宣称完成。
旧客户端在这些功能迁移前保留。生产安装、签名、升级与真实供应商验收独立进行。

验收记录见 apps/desktop/native/README.md。不以技术选型或编译成功声明达到
Codex 性能；使用本机启动、快速切换、窗口关闭、崩溃清理与失败恢复实测记录。
