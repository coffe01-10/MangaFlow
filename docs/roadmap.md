## MangaFlow 0.2.0 产品扩展 TodoList（2026-08-30）

### 版本结论

- [x] **将本轮规划定义为 `0.2.0` 里程碑。** 当前根包、Web 与 API 仍是 `0.1.0`，代表已经实现的 MVP 基线；本轮包含供应商中心地位调整、一级资产扩展、视觉编辑器、自然语言导演和桌面壳，属于明显的新功能版本，而不是 `0.1.x` 修补版。
- [ ] **在 `0.2.0` 达到发布门槛时统一修改三个 manifest 的版本号并补充变更记录。** 规划阶段只声明目标版本，不提前把未完成能力标成已发布。`plan.md` 保留 V1.0 原始 PRD 作为历史输入，新需求和实际优先级以本节为准。

### 排序原则与依赖

本轮不沿用用户输入顺序。先统一模型/供应商和可观测性底座，再补一级资产与编辑数据契约，随后建设视觉分镜和导演能力，最后完成全局文案、动效、性能与桌面封装。UI 文案精炼是贯穿每个功能 PR 的验收项，并在末尾做一次全局收口。

```text
供应商平权与统一调用契约 ─┬─> CLI 生图通道
                           ├─> 用量与成本账本/看板
                           └─> 自然语言导演与局部重绘

场景资产 + 角色模型包 ───────> 视觉分镜编辑器 ──> 自然语言导演与局部重绘

核心工作流稳定 ─────────────> 全局 UX 收口 ─────> 桌面端封装与发布
```
