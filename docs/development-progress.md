## V02-13B CLI 公共执行器已实现（2026-08-31）

- 新增 provider-neutral CLI controller 与 `CLIExecutionRun` 持久状态；每次派发关联唯一 `ModelCallAttempt`，数据库唯一槽位限制单通道并发，迁移存在审计行时拒绝降级。
